# GodSim (God Simulator)

ブラウザ上で動作する「神様シミュレーター」です。世界を創造し、そこに住む動植物や人類の発展を観察・干渉することができます。

## 🌟 主な機能

1. **WASMベースの巨大生態系シミュレーション**
   - AssemblyScript (WASM) を用いることで、数万体の植物・地形データを高速に処理。
   - 独自の遺伝子（DNA）アルゴリズムにより、環境（温度・湿度）に適応した個体が成長・繁殖・死滅を繰り返します。

2. **地形と環境のプロシージャル生成**
   - SimplexNoiseを用いて地形（山、川、海）をプロシージャルに生成。
   - 気温と湿度のマップに基づき、生育する植物（オーク、松、キノコなど）が自動的に分布します。

3. **人類の発展と職業・外交システム**
   - 人々は集落を形成し、資源を集めて文明レベルを向上させます。
   - **職業（Job）:** 人々は「農民」「木こり」「建築家」「戦士」などの職業を持ち、それぞれ異なる行動を取ります。
   - **外交と戦争:** 国同士は資源状況に応じて友好度が変化し、悪化すると戦争が勃発。ボロノイ図によるリアルタイムな国境の変化がミニマップ（Mキー）で確認できます。

4. **自然災害と神の干渉**
   - 竜巻、地震、落雷などの自然災害が気象条件に応じて自然発生します。
   - 神の権能（画面上のボタン、またはキャラクターへの憑依中の[F]キー）により、プレイヤー自身の手で天罰を下すことも可能です。
   - **100年スキップ機能:** 一瞬で100年分の時間を進め、進化と文明の発展を瞬時にシミュレーションできます。

## 🎮 遊び方

- **カメラ操作:** 右クリックで視点移動、左クリックで回転/選択、スクロールでズーム。
- **ミニマップ:** Mキー、またはUIボタンで表示。マップ上をクリックするとテレポートできます。
- **憑依モード:** キャラクターを選択し、「憑依」ボタンを押すことで、WASD移動による直接操作が可能になります。
- **再生成:** シード値を変更し、「再生成」ボタンを押すことで、異なる地形と環境の新しい世界を創り出せます。
